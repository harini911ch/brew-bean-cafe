# ☕ Brew & Bean Café

A modern, responsive café website built with React and JavaScript.

Brew & Bean is a client-style demo project designed for a café or small food business. The website provides a clean and welcoming digital presence with a menu, gallery, customer reviews, contact section, and an interactive frontend ordering experience.

## 🛒 Ordering Experience

The website includes a frontend ordering flow that allows users to:

1. Browse the café menu
2. Select a menu category
3. Add items to the cart
4. Increase or decrease quantities
5. Remove items
6. View the order subtotal
7. View GST calculation
8. Generate a bill
9. View the order number
10. View order date and time
11. Confirm the order
12. Continue browsing the menu

> **Note:** The ordering system is currently frontend-only. It does not process real payments or store orders in a backend database.

##  Getting Started

Follow the steps below to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/harini911ch/brew-bean-cafe.git
```

### 2. Navigate to the Project

```bash
cd brew-bean-cafe
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The terminal will display the local development URL.

Open that URL in your browser to view the website.

---

##  Production Build

To create an optimized production build, run:

```bash
npm run build
```

The production files will be generated inside the `dist` directory.

##  Main Sections

###  Hero

Introduces the café with a welcoming headline, supporting content, imagery, and call-to-action buttons.

###  Menu

Displays food and beverages using categorized menu cards.

Users can filter the menu by:

- Coffee & Beverages
- Freshly Baked
- Pizza & Savoury
- Desserts

###  Cart

Provides an interactive frontend shopping experience where users can manage their selected items and quantities.

###  Bill

Generates a simple order receipt containing:

- Order number
- Date and time
- Ordered items
- Quantity
- Subtotal
- GST
- Final total

###  About

Introduces the café and its story while highlighting key statistics and visuals.

###  Gallery

Displays café and food imagery with interactive hover effects.

###  Testimonials

Shows customer reviews to create social proof and improve the overall business presentation.

###  Contact

Provides café contact information and a simple contact form with a submission confirmation.

###  Footer

Contains navigation links, café information, social links, and copyright information.
